# Project shitfan
When the **** hits the fan

## What is it
Emergency reference documents per region/country. It should contain emergency phone numbers, applicable law, etc. What to do and where to go in case of emergency. National government procedures and plans, who does what. Country specific risks and scenarios.

- Template for your region/country
- AI prompts to generate for your region/country
- example document for europe/netherlands
- checklists
- in Markdown --> PDF, zim, paper

Proposed to be included in official Project NOMAD curated content.
